# Mood-Tracker

A simple mood tracking web app that lets you log and monitor your emotional state throughout the day.

## Features

- Increase or decrease your mood score with + and - buttons
- Mood score is capped between -10 and +10
- Specific mood labels that change based on your score (Ecstatic, Great, Neutral, Terrible, etc.)
- Background and text colors change dynamically based on your mood
- Mood history log with timestamps stored in your browser
- Fully responsive — works on mobile and desktop
- Mood score and history persist across page refreshes using localStorage

## Tech Stack

- HTML
- CSS (CSS Variables, Flexbox, Media Queries)
- Vanilla JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in your browser or use Live Server in VS Code
